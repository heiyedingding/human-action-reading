# 《人的行为》逐字精读 · 读书站

米塞斯《人的行为》（*Human Action: A Treatise on Economics*）逐字精读的静态读书站。
单页 `index.html`，无外部依赖、无需构建，直接用浏览器打开即可。

## 在线地址

https://heiyedingding.github.io/human-action-reading/

由 GitHub Pages 从 `main` 分支根目录发布。若访问不到，检查
`Settings → Pages → Build and deployment` 是否为 `Deploy from a branch` / `main` / `/(root)`。

## 页面内容

- **关于本书** —— 作者、版本沿革、方法立场与全书范围
- **怎么读** —— 逐字精读 / 白板推演 / 逐篇归档
- **全书结构** —— 七篇三十九章，可展开查看每篇处理的问题
- **从这里开始** —— 一条不绕弯的阅读顺序

逐篇笔记与讲稿整理中。本站不转载原书全文，涉及原书的表述以纸本原文为准。
